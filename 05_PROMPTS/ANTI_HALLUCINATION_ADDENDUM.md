# Anti-Hallucination Addendum

The AI must distinguish among: VERIFIED, INFERRED, ASSUMED, UNKNOWN and BLOCKED.

Only VERIFIED facts may be presented as repository facts.
INFERRED or ASSUMED decisions must be clearly labeled and should become documented decisions if they affect implementation.
UNKNOWN information must trigger inspection or a safe change request, not invention.

Never invent a command result, package version, file path, device result, performance number, store requirement or API.

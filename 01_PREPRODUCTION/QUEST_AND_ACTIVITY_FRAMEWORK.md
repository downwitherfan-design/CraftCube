# CraftCube v7 — Quest & Activity Framework

## Activity families
- Main story objective
- Puzzle mastery challenge
- World restoration activity
- Discovery hunt
- Companion activity
- Optional environmental puzzle
- Collection objective
- Daily/seeded challenge (online not required for core play)

## Activity quality rule
An activity must change player knowledge, skill, world state, relationship, collection, or meaningful reward. Activities that only consume time should be rejected.

## Repeatability
Repeatable activities need either variable challenge, mastery depth, new strategy, or collectible significance. Repeating the same task solely to farm currency is discouraged.

## Quest reward rule
Rewards should reinforce the player's next meaningful choice. A reward that has no future use is suspect.

# 13-Account Parallel Start Matrix

All accounts can start in parallel after receiving the Master Control Prompt, their Track Contract, and the current phase prompt.

AI-01: Product / Game Direction — product hypothesis and scope.
AI-02: Core / Simulation — technical feasibility and core contracts.
AI-03: Puzzle / Level — mechanic taxonomy and content feasibility.
AI-04: Gameplay / Mobile Interaction — touch, camera, interaction feasibility.
AI-05: Environment Art — visual direction and mobile asset budgets.
AI-06: Characters / Animation / VFX — style and runtime feasibility.
AI-07: UI/UX — mobile UX architecture and visual language.
AI-08: Audio — audio identity and implementation constraints.
AI-09: Narrative / Localization — world structure and localization strategy.
AI-10: QA — quality strategy and acceptance criteria.
AI-11: Android / Performance — device matrix and budgets.
AI-12: Build / Release — build feasibility and release requirements.
AI-13: Integration / Technical Production — cross-track risk and governance.

Rule: each account works only inside ownership. Shared contracts are coordinated through the governance process. No track blocks another when a safe mock, fixture, sample state or adapter can be used.

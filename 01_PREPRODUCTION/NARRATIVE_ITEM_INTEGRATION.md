# CraftCube v7 — Narrative × Item × Puzzle × World Integration

## Core loop
STORY HOOK → PUZZLE OBJECTIVE → PLAYER ACTION → WORLD RESPONSE → DISCOVERY/REWARD → ITEM/EQUIPMENT DECISION → NEW CAPABILITY → NEW STORY QUESTION

## Major-item rule
A meaningful item should have at least two strong connections among story, puzzle, world, exploration, companion, or progression.

## World consequence rule
If an item or story event changes the world, that change must exist as explicit persistent state and be save-safe.

## Narrative item tiers
- Common utility: frequent, light lore.
- Named artifact: strong identity and story connection.
- Chapter relic: major progression/narrative value.
- Mastery relic: optional difficult challenge reward.

## Companion connection
Some items may reveal memories, trigger reactions or unlock companion utility. Companions should not become passive inventory decorations.

## Anti-bloat rule
Do not create an item because the genre expects it. Every meaningful item needs a player-facing purpose, owner, contract, test strategy and integration path.

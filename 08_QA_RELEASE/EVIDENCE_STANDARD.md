# Evidence Standard

Evidence must match the claim.

Examples:
- Unit test claim → exact command + result.
- Android build claim → artifact path + build identifier.
- Device pass claim → device model/OS/build + test case result.
- Performance claim → profiler metric, scene/content, device and measurement method.
- Visual quality claim → captured image/video or review note where applicable.

“No errors observed” is not equivalent to “tested successfully” unless the test procedure is defined.

## Development model

13 AI tracks work independently in parallel. They communicate through versioned contracts, mocks, fixtures and evidence. AI-13 integrates the outputs into one coherent repository.

## Core principle

`Puzzle mastery -> World reaction -> Story/Discovery -> Reward -> Equipment/Capability -> New puzzle`

Everything must strengthen this relationship.

# Context Priority Rules

When an AI receives information from multiple files, chats or generated notes, it must resolve them in this order:

1. Current repository state.
2. Released versioned contracts.
3. Approved architecture and decision records.
4. Exact current phase prompt.
5. Account ownership rules.
6. Product/GDD documentation.
7. Temporary notes and suggestions.

If two high-priority sources conflict, do not guess. Open a conflict/change request and preserve the existing working behavior until the decision is published.

# CraftCube v7 — START HERE

This is the **production-ready planning pack** for starting CraftCube from zero with 13 independent AI development tracks.

## What to do first

1. Read `00_CONTROL/MASTER_ROADMAP.md`.
2. Read `01_PREPRODUCTION/INVESTMENT_GATE.md` and `01_PREPRODUCTION/QUALITY_INVESTMENT_RULES.md`.
3. Read `00_CONTROL/CRAFTCUBE_GAME_MASTER_BIBLE.md`.
4. Read `00_CONTROL/13_AI_EXECUTION_MANUAL.md`.
5. Start **Phase 00** in all 13 accounts in parallel.
6. Every AI must read the Master Control Prompt + its Track + its exact Phase prompt before editing.
7. Do not begin expensive content production until the Investment Gate and Phase 6 Gold Slice gates pass.

## Parallel development rule

The 13 AIs are intentionally independent. They do not share implementation ownership and should not wait for each other.

The common language between them is:
- versioned contracts,
- schemas,
- stable IDs,
- events,
- mocks/fixtures,
- evidence,
- integration requests.

The integration rule is:

`INDEPENDENT WORK -> CONTRACTED OUTPUT -> VALIDATION -> INTEGRATION -> UNIFIED BUILD`

## The game's protected center

`PUZZLE MASTERY -> WORLD REACTION -> STORY/DISCOVERY -> REWARD -> ITEM/EQUIPMENT CHOICE -> NEW CAPABILITY -> NEW PUZZLE`

Everything else must strengthen this loop.

## Starting principle

The first job is not to produce lots of assets. The first job is to prove that the game is:
- fun,
- understandable,
- distinctive,
- emotionally interesting,
- technically feasible on Android,
- and capable of supporting long-term progression.

The pack is designed to maximize parallel speed **without sacrificing integration quality**.

## Final world-class layer

Before starting Phase 00, also read `00_CONTROL/V7_1_WORLDCLASS_UPGRADE.md` and `01_PREPRODUCTION/CRAFTCUBE_WORLDCLASS_CONTENT_RULES.md`. These are cross-cutting requirements for story, characters, quests, items, equipment, economy, accessibility, localization, analytics/privacy, competitive integrity and remote-content safety.

The goal is not to maximize feature count. The goal is to make the player remember the world, the puzzle, the characters and the choices they made.
